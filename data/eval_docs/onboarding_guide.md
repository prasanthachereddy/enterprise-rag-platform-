# Onboarding Guide

## First Week
New employees attend an orientation session on their first Monday and complete mandatory security training within five working days.

## Accounts and Access
IT creates email and system accounts before the start date. Access to production systems is granted only after the manager submits an access request.

## Buddy Programme
Each new employee is paired with a buddy for the first 90 days. The buddy answers day-to-day questions and meets the new joiner weekly.
